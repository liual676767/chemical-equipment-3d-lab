# 化工设备三维实训室

本仓库保存化工设备三维教学网站的源码、设备素材、验证脚本和资料。项目使用 Vite、TypeScript 和 Three.js。

## 本地运行

安装 Node.js 20 后运行：

```powershell
npm ci
npm run dev
```

执行 `npm run build` 进行内容检查、类型检查并生成 `dist`。浏览器中的学习记录和装配方案保存在当前网站的本地存储中，不同域名之间需要通过网站内的导出和导入功能迁移。

`public/models/uploads` 中包含用户上传的第三方模型，具体许可及再分发范围有待确认。程序化教学模型和工艺为教学示意，具体设备型号及现场工艺参数以可追溯资料为准。
