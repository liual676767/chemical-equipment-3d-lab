# 三维教学工厂 · 水性涂料调配车间（教学案例）

> 入口：站点首页 `#/`。设备库（原首页）迁至 `#/library`，既有深链（`#/device/:id`、`#/workshop`、`#/plant`、`#/boil`、`#/assets`）全部保留。
> 本文登记工厂的数据、交互与内容边界；所有位号、管线编号、管径等级、颜色与动画均为教学示意，不是工程设计或工艺参数。

## 1. 教学案例与依据

- 案例：**水性涂料调配车间**（用户在第 14 轮指定）。路线：收料与计量投料 → 预混分散 → 调配 → 取样检验放行 → 泵送 → 过滤 → 灌装 → 成品暂存。
- 参考：Queen's University 等团队的虚拟化工厂（PCEEA 论文，用户提供链接）。本轮两次抓取该论文均失败（重定向过多 / 下载地址不可达），实现按用户描述的四项体验落地：厂区参观、管仪图（以「教学流程图」呈现）、设备寻址任务、场内行走导航。**未引用论文原文内容**。
- 设备结构来源：`devices.ts` 的 18 台设备为本站既有程序化教学模型；本车间复用其中 9 类整机（储罐、反应釜、离心泵×2、隔膜泵、空压机、袋式过滤器、闸阀、球阀、电磁流量计）。法兰/垫片/螺栓尺寸依据沿用 `src/workshop/specs.ts` 中已登记的 GB/T 17395 外径与 PN16 法兰参数（教学核对口径，非施工数据）。
- 检索词登记（用于资产追踪与复用检索）：
  - `virtual chemical processing plant P&ID equipment identification quest`
  - `waterborne paint manufacturing dispersion let-down filtration filling layout`
  - `AODD pump exploded view STEP`
  - `simplex bag filter support basket cutaway`
  - `FreeCAD parametric piping flange gasket elbow reducer`

## 3. 介质与管线（13 段）

| 介质 | 颜色 | 相态 | 说明 |
| --- | --- | --- | --- |
| 原料浆料 | 蓝 | 液 | T-201 → P-201 → 计量 → R-201 |
| 粉料/助剂 | 紫 | 液（示意） | 平台投料口 → R-201 顶部辅料口（人工投料） |
| 预混浆 | 琥珀 | 液 | R-201 → P-203 → R-202 |
| 样品 | 粉 | 液 | R-202 取样口 → 取样阀 → 取样口（检验放行） |
| 成品涂料 | 绿 | 液 | 已放行的 R-202 → P-202 → F-201 → FL-201 |
| 桶装成品 | 绿 | 桶装 | FL-201 经 PL-210 教学辊道 → ST-201 |
| 压缩空气 | 黄 | 公用工程 | C-201 → P-202 气侧（架空跨走道） |
| 清洗液 | 青 | 液 | F-201 排净 + 清洗来液（示意端头）→ CL-201（不外排） |

管线编号 PL-201…PL-213，起点/终点/路由点全部登记在 `FACTORY_PIPES`；路由点为教学走线，不代表施工布线。流向箭头全站统一为琥珀色一套；介质色仅用于管体与示踪粒子。

**可拆卸法兰接头**：`JOINT-201`（PL-208 上 t=0.42，DN50 PN16），连接「泵侧法兰密封面（P-202 出口）」与「过滤器侧法兰密封面（F-201 进口）」，是法兰练习入口。

## 4. 厂房布置（教学示意）

- 建筑约 45.5 × 24 m，高 8 m；**前墙与屋顶默认隐藏**，顶部工具条可分别显示。
- 走道网络：南侧主走道（x −18…24.4，z=2.5）＋北侧走道（z=−6.8）＋东西两条连接走道＋过滤器/灌装机/清洗桶支路；黄色边界条，均抬高 60 mm。
- R-201 北侧投料平台（2.3 m 高，带栏杆与踏步楼梯），对应「平台投料口（教学示意）」。
- 分区地坪色块：Z0 收料与计量投料 / Z1 预混与调配 / Z2 泵送与过滤 / Z3 灌装与暂存。
- 长距离管线自动支吊架；靠近设备/阀门/仪表/接头处跳过支架。

## 5. 交互

1. **标签分两层**：远景（相机距目标 >34 m）只显示分区名（工序名）；近景显示设备位号与名称；选中时显示该设备的接口热区（进口/出口/公用工程口）与管线标签。
2. **近景简化**：距相机 >30 m 的设备切换为简化外形（圆柱/方块），保留同一拾取身份（点击仍选中该位号）。
3. **设备卡片**：名称/职责/接口/物料上下游/可操作项（沿下游查看、走近查看、外观参照/内部教学结构、零件工作台、阀门开度）。「沿下游查看」用 `traceFrom` 高亮真实相连管线段并定位下一段管线；点击高亮设备继续追踪。
4. **教学流程图**（左下角、可收起）：按 8 道工序分列的设备符号与管线连线，与三维共用同一套位号/管线编号；点流程图设备=选中该实例，点三维管线=流程图对应连线高亮；图中的管线颜色即介质色，淡线无上游供给，虚线表示受限或被阀截断。缺完整仪控数据，故不称 P&ID。
5. **设备细节浮层**（`#/detail/:uid`，进入前记录相机与选择）：同视角切换「外观参照 ↔ 内部教学结构」（GLB 外观来自 `assets/registry.ts`，差异一句话随浮层展示）；接口清单可点击识别；返回厂区（按钮/Esc）与浏览器后退都恢复进入前视角与选择。动作事件会同步到样板任务进度。
6. **法兰练习**（`#/practice/JOINT-201`）：复用工坊连接引擎（`validateConnection / makeConnection / jointSlots / slotWorld`）与零件几何。托盘含密封垫片 DN50×1、M16 螺栓/螺母各×4、M12 螺栓/螺母各×1（干扰项）。未装垫片就装螺栓会点名「泵侧法兰密封面 ↔ 过滤器侧法兰密封面」缺件；M12 件触发「该法兰连接需要 M16 螺栓」规格提示。完成后写本厂记录。
7. **样板任务**（右上「样板任务」）：10 步状态机，只接受与当前步骤匹配的真实操作事件（选中设备、外观切换、接口识别、关闭细节、打开练习、完成练习）。可「定位当前目标」；任务完成后记录实际识别/连接对象。自由漫游与任务共用同一座工厂。
8. **行走模式**：使用 WASD、键盘方向键或屏幕方向键移动，拖动调整视角，Esc 恢复进入前的视角。点「到投料楼梯口」可面向现有楼梯，向前沿八级踏步登上 R-201 投料平台，回到楼梯时逐级下降。相机眼高随踏步变化，楼梯两侧和平台边缘设有行走限制。踏步高度直接取自现有教学几何。
9. **搜索**：设备位号/名称/管线编号/介质名；场内实例直接定位；仅设备库案例的机型标注「仅在设备库案例」并跳转 `#/device/:id`。
10. **记录**：新键 `chem3d-factory:v1`（到访设备、样板任务、法兰练习）。**不改动** `chem3d-lab:v1`、`chem3d-workshop:v1`、`chem3d-lab:quality`。

「从收料开始」在 T-201 打开定性因果练习。按份数推进，经 R-202 取样和教学判定后才能进入 P-202 的物料侧。暂缓批可登记隔离台账，待实际处置资料。灌装桶先停在 FL-201，下一轮由 PL-210 进入 ST-201 暂存。排净和清洗来液分别进入 CL-201。份数不对应工程计量。

## 6. 数据校验与验收

- 数据自检 `auditFactoryData()`：位号/管线/接口引用、起终点流向（出口→入口）、分区与工序归属、全开阀可达性、接头引用。开发页 `window.__factoryAudit()` 可查。
- `npm run verify:factory`（Playwright + Edge，桌面 1440×900 / 手机 390×844）：54 项，覆盖总览、管线与流程图联动、细节开关与视角恢复、浏览器后退、行走、外壳、阀门、搜索、10 步样板任务（含缺垫片点名与 M12 规格提示）、记录与记录隔离、旧入口回归、手机全样板。
- `npm run verify:factory:stairs`：验证八级踏步升降、楼梯侧面限制、平台行走与边缘限制、屏幕方向键和 Esc 视角恢复。
- 生产构建：`npm run build` 通过（内容校验器 + tsc + Vite）。

## 7. 内容边界与缺口

- 本车间没有真实工艺图纸/设备表/管道表（用户未提供），路由、坡向、支吊架位置均为教学示意；不标注为工程管线。
- 本轮未新增外部 CAD/网格资产：厂房、走道、平台、管线、支架、法兰练习件均为程序化几何；外观参照复用既有 13 件 GLB（GLTFLoader + MeshoptDecoder）。因此未使用 FreeCAD/OSE Piping Workbench/Blender/glTF Transform 流程，也未新增许可登记。
- 灌装机内部计量机构、清洗桶容积与材质、投料平台尺寸为**待确认**；已在界面与台账标注。
- 压缩空气只接到 P-202 气侧；清洗液只进独立收集桶，不外排、不与主工艺互连。
- 产品去向（出库）不在本案例范围；成品暂存区仅示意托盘码放。
- 与 `#/plant` 化工厂全流程装置相互独立：编号体系不同（T-101… 与 T-201…），教学用途不同，不得混用。
- 微沸喷烧全流程（`#/boil`）与本车间无物料连接：站内没有证据表明其废液进入本车间，按用户要求不建立连接。
