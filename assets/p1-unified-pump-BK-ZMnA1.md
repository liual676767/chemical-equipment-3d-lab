# P1 离心泵与法兰样板

本地工作区以 P0 核实的原项目源码建立。P1 保留 `pump` 及 40 个零件 ID、8 件练习顺序、学习内容版本和 `JOINT-201`。教学单位沿用设备工作台的米制比例和工坊的 100 mm/场景单位，两个库的比例用途分别说明。

## 设备、资产与几何

- 工作台用同一个 `SceneManager` 管理离心泵，载入一套零件对象。整体观察中的「近看外观」在同一泵壳上切换网格，两档保留蜗壳、吸入口、排出口和部件安装基准。剖视、透明、原理、内窥和拆装使用精细蜗壳。叶轮、轴、密封和轴承零件两档共用，身份和配合基准保持一致。
- 蜗壳使用 Three.js 和项目已有的 CSG 构造同一连续空腔，开放叶轮室、吸入口和排出接管。修复泵盖和轴承端盖的轴通孔、键槽的圆周轮廓、断开的阶梯轴段、轴承座配合、密封轴套与压盖间隙、弯头的端面方向和异径管朝向。原理示踪与内窥读取同一通道数据。旋转叶片区由可观察叶轮及内窥教学路径表达，粒子示踪沿吸入及排出段显示。
- 卧式泵组上传资产仍在原素材入口，工作台标为「上传外观对照」。其泵型、吸排口和支承/安装基准尚未确证，P1 采用站内程序化几何生成近看蜗壳。未改动原 GLB。
- 工厂 P-201 详情进入工作台后，选中的设备和场景视角存于当前浏览器历史条目。退出内窥恢复进场前视角。工作台的主要模式切换沿用选中部件和镜头目标。通用装置与微沸喷烧的完整来源状态恢复属于 P3。
- `JOINT-201` 使用工坊已有法兰、管长、垫片和螺母尺寸函数。垫片两面都成立才提交，两边的焊接管组保持安装位。练习的螺栓头贴外侧承压面，螺母贴另一侧，孔圈、螺栓和垫片共用该教学接头。通用工坊的旧螺栓连接和存档结构继续兼容。

选择程序化网格作为权威几何，已验证型号的外部资产以后可增加同基准视图。现有外部 GLB 只有装饰级外观资料，直接替换会丢失内部语义、界面选择和入口配合。工作台拥有设备交互状态，来源页面拥有返回快照，工坊规格和接口模块拥有法兰配合数据。浏览器历史只持有当前学习路径的小型快照。

结构依据为卧式蜗壳离心泵的轴向吸入、旋转叶轮、壳体出口原理，以及板式/带颈法兰、平垫的典型连接关系。尺寸均为本站演示值。蜗壳旧记录中的“1.88 圈”属于旧版截面生成方式的误写，P1 改用一周变半径轮廓。 [KSB 泵壳词条](https://www.ksb.com/en-global/centrifugal-pump-lexicon/article/pump-casing-1118596) · [Nikal Steels EN 1092-1 目录](https://nikalsteels.ie/wp-content/uploads/2022/03/en-flange.pdf) · [历史精度台账](pump-accuracy-record.md)

## 运行结果

环境为 Node 20.18.1、Vite 5.4.21、Three.js 0.160.1、TypeScript 5.9.3、项目已装 Playwright Core 和 Edge 157.0.4341.60。浏览器使用 SwiftShader，当前不据此评价真实 GPU 性能。

| 检查 | 结果 |
|---|---|
| `npm run build` | 内容校验、喷烧内部结构校验、类型检查和 Vite 生产构建通过。沿用旧内容门禁中的可拆件未纳入练习步骤提示 |
| `node scripts/verify-pump-geometry.mjs` | 40 个零件、固定底座、8 个拆装对象保留。蜗壳总组在总览和精细档分别约 15,149 / 36,603 三角形，两档包围范围在声明误差内，45 段代表性静态流路未与所查网格相交，泵盖和轴承箱等部件的轴线通道未被封死。抽查轴段连续 |
| `node scripts/verify-unified-pump.mjs` | 真实点击 P-201→工作台，选叶轮，缩放，切换外观、剖视、原理、内窥和拆装；相机及选中身份核对，返回、浏览器前进及后退均通过 |
| `node scripts/verify-pump-comparison.mjs` | P0/P1 同一 1440×900、DPR 1、高画质、同相机位置和目标、同剖视模式，核对画布相同 |
| `node scripts/verify-pump-template.mjs` | 36/36，桌面/移动视口、剖视、内窥、恢复及练习入口 |
| `node scripts/verify-factory.mjs` | 54/54，含两尺寸、法兰练习、错 M12 提示与完整样板任务 |
| `node scripts/verify-records-compat.mjs` | 旧记录迁移、收藏与成绩、自测及任务导入导出通过 |
| `node scripts/verify.mjs`、`node scripts/verify-workshop.mjs`、`node scripts/smoke-prod.mjs` | P1 全站 174/174、工坊 56/56、生产冒烟 22/22 |

真实使用验证以工作区本机开发服务 `http://127.0.0.1:48118/` 为主。前后对照的 P0 服务来自已核对临时源快照。最初运行曾遇到浏览器选择器、视角被 ResizeObserver 的初始取景覆盖及截图超时，修正或复跑后的结果见 `outputs/verify-p1/`。P2 的空间算法和代理仍在开发，P1 的构建与验证不包含其运行时行为。
