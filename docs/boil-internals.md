# 微沸喷烧 Phase 7：核心设备内部结构（教学示意）

> 2026-11-18 · 独立模块（未接入站点路由、未发布）
> 对应总任务 Phase 7「核心设备内部结构升级」。与并行 Phase 5（工艺分层）/ Phase 6（追踪与播放）文件无交集；不改动 `src/boil/*`、`src/data/boilProcess.ts` 与流程数据。

## 1. 目标与范围

- 让 14 类微沸喷烧教学设备都能观察内部结构，而不是只有外壳。
- 每台设备支持五种观察模式：正常外观 / 透明观察 / X 射线 / 局部剖切 / 内部观察。
- 覆盖 18 个流程设备实例（四根喷枪、集冷塔一/二为独立实例，共用同型教学内部结构）。
- 二燃室的四根喷枪为四个独立可选部件；回转窑、布袋除尘器、集冷塔、综合塔、水洗塔、湿电除尘、引风机按要求提供关键内部教学结构。
- 全部内部结构为参数化**教学示意**，不是设备图纸、制造依据或现场内部结构；不含温度、压力、流量、电气、型号、材料牌号等工程参数。

## 4. 五种观察模式

| 模式 | 实现方式 | 教学口径 |
| --- | --- | --- |
| 正常外观 NORMAL | 仅外部模型可见；内部隐藏 | 识别设备外形与外部附件 |
| 透明观察 TRANSPARENT | 外壳材质幽灵化（不透明度 0.16），内部显示 | 观察内部部件相对位置；不代表真实材质透明 |
| X 射线 X-RAY | 外壳蓝色线框幽灵 + 内部显示 | 结构辨识可视化；**不是**真实射线检测或探伤 |
| 局部剖切 CUTAWAY | 外壳沿演示平面（Z 正半轴）几何裁剪，内部显示 | 裁剪面**未做封口填充**，不表示真实壁厚或截面；不能作制造/测绘依据 |
| 内部观察 INTERNAL | 隐藏外壳、镜头聚焦内部包围盒 | 近距离观察内部教学结构；无壳体参照时部分内件可能显得悬浮 |

补充：
- 选中部件以浅蓝包围框 + 标签高亮，结构树与三维拾取双向同步；正常外观下选择内部部件会自动切换到透明观察。
- 部件标签默认关闭；开启后按“内衬/驱动/喷枪/管路”类别显示（内部空间与流线标签仅在选中时显示），并按相机距离保持屏幕字号，避免内部观察时标签过大。
- 动画可暂停；动画仅用于教学演示，不代表真实转速、流量或工艺过程。

## 5. 内容边界与待确认项

- 全部内部结构为参数化教学几何；**没有**厂商图纸、设备总图、现场测绘、P&ID、内件规格或专业评审。
- 以下内容未提供，已在数据中标注 `pending-confirmation`，不得用占位值填充：
  - 二燃室：四根喷枪的接入位置、角度、喷入介质与配比；炉膛结构与燃烧组织；是否设置底部排灰；
  - 炉塞泵：泵型（柱塞/螺杆/其他）与内部运动；
  - 回转窑：筒体尺寸、倾角、转速、内衬材质与厚度、物料运动；
  - 布袋除尘器：滤袋数量/材质/尺寸（12 条仅为教学布置）、花板孔位、清灰方式与参数；
  - 集冷塔/综合塔/水洗塔：喷淋层数、填料类型与规格、循环量与水质；
  - 湿电除尘：极板/极线数量与间距（5 块/4 根为教学布置）、电气参数、冲洗方式；
  - 引风机：风机型式、叶轮直径/叶片数、风量/风压、真实转速；
  - 烟囱：内衬、采样/监测点位与排放参数（不假定排放达标）；
  - SMP：内部组成与是否集成破碎/混合/泵送。
- 内部结构文档只描述“教学上如何观察”，不能作为工程设计、采购、施工、安全评价或工艺包依据。
