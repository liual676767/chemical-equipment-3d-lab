## 2. 统一工业建模标准（第五轮起执行）

1. **零件独立**：每台设备的可辨识结构均为独立 Group 与独立目录条目（原 id 不删除）；固定焊接/铸造结构如实标 `fixed/display`。
2. **中空管道**：外径/内径/壁厚/内壁/外壁/环形端面齐全，管口真实开放（共享助手 `src/engine/industrial.ts: hollowCylX/Y`）。
3. **法兰真孔**：螺栓孔为几何孔（Shape+孔挤出），并标记 `userData.boltHoles` 供验收。
4. **材质分档**：PBR + 环境贴图；铸造/加工/涂装/橡胶/玻璃分档粗糙度与金属度；统一蓝色系工业涂装。
5. **细节有据**：只添加与结构相符的螺栓、垫片、加强筋、轴肩、键槽、密封面；不堆砌无意义零件。
6. **教学示意边界**：无图纸处使用演示参数并在界面/文档标注；不编造型号与工程尺寸。
7. **验收**：每批次跑 build（内容门禁含建模覆盖）+ 浏览器自动化（专项脚本）后才更新状态。
