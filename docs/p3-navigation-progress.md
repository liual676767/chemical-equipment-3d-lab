# P3 视野与场景返回验收记录

## 实际修改

- 通用装置的启动说明移到「更多」。暂停时可直接点设备、管线和工序。动画速度、内部视图、名称标签、镜头复位和学习记录收进同一菜单。手机宽度下，工序目录、流程图、设备信息卡按当前操作打开，Esc 关闭当前界面并归还焦点。
- 从通用装置信息卡进入工作台时，来源历史项保存相机、目标点、设备或管线、激活工序、教学步号、追踪、阀门、单机和运行状态。返回时恢复镜头并保护首次尺寸变化重置。
- 水性涂料厂区的设备卡片、设备细节和搜索入口共用厂区快照。返回恢复镜头、选择、焦点范围、运行与阀门状态、分栏和任务状态。原始设备位号、流程与学习记录沿用现有数据。
- 微沸喷烧从追踪或流程回放进入同一设备结构观察，采用同一 modelKey 的外观和内部几何。开放布袋、水洗塔、湿电与引风机四种教学观察。观察期间原场景和流程状态保留，关闭后可继续当前步骤。直接打开设备深链时，返回微沸流程总览。现场参数、内件配置与现场操作仍以现有待确认资料为准。
