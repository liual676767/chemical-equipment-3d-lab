# P4 三套工艺的依据与因果关系

设备、端口、介质和原入口以冻结的 P3 源码为准。P0 已逐项登记静态工序和未知项。下表补充动态条件、可完成的教学任务和现场资料缺口。三套案例的示踪状态只说明本次教学通路。涂料的离散份数用于练习转移和守恒，未采用真实容量、流量或时钟。通用装置为独立单元的定性演练，微沸喷烧为沿清单的观察回放及结构辨认。 [P0 工艺台账](../../化工实训室-P0基线-20261121/02-三套工艺与资料台账.md)

## 水性涂料调配

| 工序和关系 | 操作条件与观察结果 | 现场待核 |
| --- | --- | --- |
| 收料和计量，T-201 罐底经 GV-201、P-201、FT-201 与 BV-201 到 R-201，PL-201、PL-202 | 打开所需通路，P-201 与预混分散器可用时推进。选择「从收料开始」时调配罐为空。原料耗尽后储罐出口停示踪，已有预混存量保留。 | 原辅料组分、实配量、计量范围和投料许可。 |
| 预混分散与调配，R-201 经 P-203 到 R-202，PL-204、PL-205。PL-203 是人工投料的示意支路 | 先有预混存量、泵和搅拌驱动，下一轮才可送调配罐。取样后暂停并入新预混浆。混合和分散按物理过程观察。辅料没有单独的数量模型。 | 配方、加料顺序、分散终点和黏度。 |
| 取样与放行，R-202 经 SV-201、PL-206 至取样边界 | 调配罐有料、搅拌和取样通路可用后，扣一份进样品台账。选择教学放行后 PL-207 才可输料。暂缓保留罐内存量，可登记到教学隔离台账后开启下一批。 | 检验项目、质量标准、实体隔离位置与处置规程。 |
| 放行出料、驱动及过滤，R-202 经 PL-207 至 P-202 液侧。C-201 经 PL-211 至同泵独立气侧。泵出口经 PL-208 至 F-201 | 液路和驱动空气同时可用并启用泵，才能送到过滤器。阻力增大时示踪限流。堵塞暂停进出液并保留已进入过滤器的存量。教学步进仍以整份为单位，无压差和通量计算。 | 供气压力、气耗、排气、滤袋规格、可用压差和滤后存液。 |
| 灌装与暂存，F-201 液侧出口经 PL-209 和 BV-204 到 FL-201，桶装成品经 PL-210 到 ST-201 | 可用过滤存量先进入灌装工位。下一轮已有的灌装桶才能进入暂存；流程图分别显示液路和桶装辊道的通路状态。 | 灌装计量、包装规格、辊道驱动和入库条件。 |
| 排净与清洗收集，F-201 经 PL-212 到 CL-201；独立清洗来液经 PL-213 到 CL-201 | 排净与清洗模式分别关闭生产路径，前者移动过滤器留存，后者消耗清洗来液，两者进入同一独立收集点。用完后停止，不在模型中外排。 | 清洗介质、动力、隔离方案和独立收集后的处置路径。 |

正常路径从 T-201 开始，推进至 R-202 后取样、放行、过滤、灌装和暂存。异常练习包括先放行、关取样阀、暂缓、撤销气源、堵滤路、清洗来液耗尽。份数守恒包含样品、暂存、隔离、排净和清洗液。选择「从收料开始」或「重置教学批次」会重新装载当次练习的初始库存。制漆参考适用于物理调配，膜片参考适用于空气与液体的隔离和驱动关系。 [EPA AP-42 §6.4](https://www.epa.gov/sites/default/files/2020-10/documents/c06s04.pdf) · [Wilden 气动双隔膜泵原理](https://www.psgdover.com/docs/default-source/wilden-docs/white-papers/wilden_white-paper_aodd-pumps-primer-1015.pdf)

## 通用化工装置

| 工序和关系 | 条件、输出和学习动作 | 现场待核 |
| --- | --- | --- |
| 储存、切断和输送，T-101、GV-101、P-101、CV-101，PL-101、PL-102 | 切换有料、泵和闸阀状态，查泵吸入侧与出口的区别。闸阀为全开/关；止回阀由正向供给被动启闭；演练不计停泵时的重力流、旁通和倒流。 | 吸入压头、液位和停泵后的现场压差。 |
| 过滤和计量，ST-101、FT-101、BV-101，PL-102 | 可辨认 Y 形过滤器截留、流量计和球阀隔离。 | 滤网规格、压降和实际计量范围。 |
| 预热 E-101，工艺 PL-102、103 与独立热媒 PL-116、116R | 关闭热媒后热媒进回停示踪，工艺侧保留供料。温差、换热量和出口状态待资料。 | 实际热媒、进出口温度和设备换热能力。 |
| 反应釜 R-101，PL-103、104、105、106 和夹套 PL-120、121 | 观察主辅料和夹套路径，切换搅拌驱动辨认出料状态。没有反应式、产品或反应程度计算。 | 原辅料、产品、热负荷和操作条件。 |
| 冷却 E-102，壳程 PL-106、107 与管程 PL-117、117R | 关闭冷却水后进回水停示踪，壳程仍可通。可以辨认流通和实现降温需要不同条件。 | 冷却水来源、物料相态及温差。 |
| T-102 填料段，PL-107、108、114 | PL-107 是塔进液，塔内只显示下行液体。塔顶默认停运；独立演示在 PL-108 起点给出假设气相，无塔内上升气体。 | 塔用途、气源或相变热源、回流和回收组成。 |
| 假设冷凝和分离，E-103、V-102，PL-108 至 PL-112 与 PL-118/118R | 用独立塔顶示意和冷源观察冷凝液与不凝气两条去向。撤去冷却水仍可看到 PL-108 供给，暂停下游冷凝分离示踪。 | 冷凝所需相态、组分、温压和现场冷源。 |
| 精滤、储存和旋风捕集，F-101、BV-102、T-103、CY-101，PL-110 至 PL-113 | 假设冷凝支路可用时，从蝶阀比较定性部分开启。旋风只显示惯性捕集的结构作用和高点气侧边界。 | 分离介质、粒径、截留物、余气处置和排放结果。 |
| 回收和公用工程，P-103、C-101、T-101，PL-114、115、119 | 撤销 P-103 独立示意气源时，来液可留在吸入侧，回收停示踪；PL-119 仍独立供气至边界。原料罐有料由单独条件控制，回液没有自动补料计算。 | 回投条件、实际气路、仪表气用户与存量。 |

正常练习跟踪原料输送和两股换热通路，再单独启用塔顶观察。异常练习切换热媒、冷却水或独立回收气源，辨认哪些线停、哪些仍可通。流程图从设备端口与管线定义推导工序级连线，动态通路状态取三维同一结果。填料湿洗参考用于认识特定类别的气液接触，本站 T-102 塔用途待确认。 [EPA 填料湿洗气液接触](https://www.epa.gov/air-emissions-monitoring-knowledge-base/monitoring-control-technique-wet-scrubber-gaseous-control) · [EPA 旋风分离](https://www.epa.gov/air-emissions-monitoring-knowledge-base/monitoring-control-technique-cyclone) · [Alfa Laval 垫片板换流道](https://www.alfalaval.com/microsites/gasketed-plate-heat-exchangers/tools/how-gphes-work/)

## 微沸喷烧

| 区段或设备 | 输入、驱动和输出的观察内容 | 现场待核 |
| --- | --- | --- |
| SMP、破碎、混合、炉塞泵，pipe-material-01 至 04 | 沿原清单回放物料示踪至二燃室边界。可辨认破碎和混合的机械作用与泵送职责。 | 物料相态、配比、型号、炉塞泵型式及驱动。 |
| 二燃室、回转窑与四根喷枪，pipe-gas-01 | 三维/详情沿清单显示二燃室至回转窑，将顺序冲突标到设备、管线和二维图。喷枪可单独观察四个平行支路，8 个接管未连。 | 竣工 PFD/P&ID、物料和烟气分界、燃烧热源、窑渣去向、喷枪介质、雾化与接管。 |
| 集冷塔一、布袋、集冷塔二，pipe-gas-02 至 05 | 选布袋除尘器辨认压差、滤袋截留、净气室和灰斗，可从题卡定位灰斗。气侧继续显示清单连线，粉尘留在灰斗的原理位置。 | 集冷/急冷的现场名称和工作型式、冷源、清灰与真实输灰。 |
| 综合塔、水洗塔，pipe-gas-05 至 07 | 综合塔角色按清单列为待核。水洗塔观察喷淋接触、除雾和液体收集，题卡可定位收集侧。 | 综合/中合塔命名与机理，现场喷淋、气液接触和循环补排/处理。 |
| 湿电、引风机、烟囱，pipe-gas-07 至 09 | 选择湿电除尘，定位冲洗结构，辨认电场负责捕集、液体带走截留物，气侧沿原路线到引风和高点。 | 现场极板、电气、冲洗、集液去向、引风联锁与排放。 |

正常路径沿设备树、回放或追踪进入布袋、水洗、湿电，先看结构再判断去向。缺口练习辨认气侧连线为什么不能回答灰/液的下游去向，以及确认顺序需要的本案例资料。17 项现场待确认、8 个喷枪未接接口和现场启停、吹扫、联锁、急停边界仍在。JRC 图 2.9 为典型回转窑到二次燃烧室，和本教学清单的示踪方向不同。湿电结构参考与教学模型采用相同的线板类别作为原理对照。 [JRC 焚烧 BREF，图 2.9 和 2.35](https://publications.jrc.ec.europa.eu/repository/bitstream/JRC118637/jrc118637_wi_bref_2019_published.pdf) · [EPA 湿式洗涤](https://www.epa.gov/air-emissions-monitoring-knowledge-base/monitoring-control-technique-wet-scrubber-gaseous-control) · [EPA 线板式湿电](https://nepis.epa.gov/Exe/ZyPURL.cgi?Dockey=P1008OHV.TXT)
