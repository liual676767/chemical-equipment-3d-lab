# 化工厂全流程装置（#/plant）说明 — 第 8 轮系统级升级

> 本页是**教学示意流程**：设备按通用化工流程连接，位号、管线编号、管径等级、管位、介质颜色、阀门状态与动画均为教学演示，不代表任何具体产品、工艺参数或工程设计，也不是可施工的管道设计。
> 设备模型复用实训室零件级教学设备；接口位置由教学模型几何换算，具体结构与来源边界见 [sources-and-review.md](sources-and-review.md)。

## 1. 定位与入口

- 首页「化工厂全流程装置」入口卡 → `#/plant`；与设备库（单台设备）、组装工坊（手动搭建）并列，三者数据独立。
- 本页只读取 `src/data/devices.ts` 的设备定义与构建器，不修改设备内容版本与学习记录；不新增零件编号。
- 第 8 轮把原来「手绘折线 + 独立摆放小件」的演示升级为数据驱动的流程系统：**设备—接口—管线—阀门/仪表—介质—工序—工艺层** 七层关系全部落到 `src/data/plant.ts`，三维场景与页面 UI 只消费这份数据。

## 2. 数据模型（唯一内容源）

### 2.1 关系链

```text
设备实例（PlantNodeDef）
  ├─ 接口 PortDef[]           设备局部坐标 + 外法线 + 入口/出口角色 + 管径等级
  ├─ 内联安装 InlineMount     阀门/过滤器/流量计挂接到某根管线的相对位置
  └─ 工序/工艺层             step / layer

管线（PipelineDef）
  ├─ 起点/终点：设备接口 或 盲板示意端头
  ├─ 介质/管径等级/所属层
  ├─ 路由转角点（不含两端接口短节，场景自动生成短节与法兰）
  └─ 线上阀门/仪表（由内联件与仪表表反查）
```

### 2.2 关键类型与约定

| 类型 | 位置 | 说明 |
| --- | --- | --- |
| `PlantNodeDef` | `src/data/plant.ts` | uid/位号/职责/内部结构/层/工序/坐标/旋转/抬高/动画/接口/内联挂接 |
| `PortDef` | 同上 | 接口 id/名称/局部坐标/外法线/角色（in/out/both）/管径等级；`added` 表示模型本身未建、由场景补充的示意接管 |
| `PipelineDef` | 同上 | 管线编号/名称/起终点/介质/管径等级/层/路由点/说明 |
| `InlineMount` | 同上 | 管线 id、弧长相对位置 t、阀门体中心高度、阀门类型 |
| `ProcessStepDef` | 同上 | 工序号/标题/说明/主层/设备清单/管线清单 |
| `ProcessLayerDef` | 同上 | L0–L6 功能/输入/过程/输出/设备/地面示意分区 |
| `MediumDef` / `PipeSizeDef` | 同上 | 介质颜色/相态/说明；管径等级仅用于教学图示 |
| `InstrumentDef` | 同上 | 线上仪表位号/类型/管线/位置/演示说明 |

- 接口方向采用**外法线**：管线从出口离开设备、从入口进入设备；数据自检会校验“起点必须是出口、终点必须是入口”。
- 接口坐标取自 `devices.ts` 零件几何与构建器中真实接管的法兰位置（如储罐罐底出口 `x≈0.88 m`、卧式换热器壳程上进口、塔上部进液口等）；模型未建的口（反应釜出料、齿轮泵进出口、气液分离器液相口、压缩机空气出口）以 `added: true` 标注，场景绘制示意接管后再接法兰，不伪装成原模型自带接口。
- 管线两端由场景换算成世界坐标后**自动生成**接口短节、配对法兰（含螺栓）与弯头接头；路由点只描述中间走向。

## 3. 工艺层（L0–L6）

层是**流程阶段**，不是建筑楼层；地面用低透明度分区与 `L0 · …` 标签提示边界；另设 3 m 示意标高尺。

| 层 | 名称 | 作用 | 输入 | 主要过程 | 输出 | 设备 |
| --- | --- | --- | --- | --- | --- | --- |
| L0 | 原料与公用工程层 | 储存原料并提供公用工程接口（示意） | 外部来料（示意）、空气 | 储罐缓冲 → 罐底切断阀 → 泵吸入；压缩机供仪表空气 | 原料 → L1；仪表空气 → 总管（示意） | T-101 / GV-101 / C-101 |
| L1 | 输送与预处理层 | 升压、过滤、计量、预热 | L0 原料、外部热媒（示意） | 泵送 → 止回 → Y 型过滤 → 电磁计量 → 球阀 → 板式预热 | 预热原料 → L2 | P-101 / CV-101 / ST-101 / FT-101 / BV-101 / E-101 |
| L2 | 反应层 | 原料与辅料混合反应 | 预热原料、辅料（示意） | 齿轮泵加料 → 搅拌 → 夹套换热（示意） | 反应液 → L3 | R-101 / P-102 |
| L3 | 冷却与塔内分离层 | 观察管程冷却水和塔内液路 | 反应液、冷却水（示意） | 壳程出料到塔上部，塔内仅示踪下行液体 | 塔底液 → L6；L4 气源单独演示 | E-102 / T-102 |
| L4 | 冷凝与气液分离层 | 冷凝塔顶气相并分出冷凝液/不凝气 | 塔顶气相、冷却水（示意） | 冷凝 → 立式气液分离 | 冷凝液 → L5；不凝气 → L6 | E-103 / V-102 |
| L5 | 产品精制与储存层 | 精滤后储存产品 | 冷凝液 | 袋式精滤 → 蝶阀出料 → 成品罐 | 产品（终点） | F-101 / BV-102 / T-103 |
| L6 | 尾气与回收层 | 尾气捕集排放、塔釜液回收循环 | 不凝气、塔釜液 | 旋风分离 → 高点排放（示意）；隔膜泵回收 | 排放（示意）；回收液回 L0 原料罐 | CY-101 / P-103 |

### 5.3 管径层级与工业细节

| 等级 | 外半径（教学图示） | 用途 |
| --- | --- | --- |
| 主工艺 `main` | 0.075 m | 主物料线（PL-101~PL-115 中 13 根） |
| 支管 `branch` | 0.05 m | 辅料、尾气排放 |
| 公用工程 `utility` | 0.035 m | 蒸汽/冷却水/仪表空气 |
| 仪表/取样 `instrument` | 0.02 m | 预留，本轮未单设仪表管 |

- 每根管线两端：接口短节 + 配对法兰（带螺栓）+ 管道端法兰 + 弯头接头；接口转角与短接自动生成，不在设备外壳上悬空开孔。
- 自动支吊架：低管位用双腿支架 + 横梁 + 管卡，高管位用立柱 + 悬臂 + 管卡；回收液长距离线与仪表空气总管设管廊/支架（`PL-115`、`PL-119`）。
- 阀门/过滤器/流量计为**内联安装**：按管线弧长定位，阀体轴线对齐管道切线，无独立基础；阀门可用状态按切断、调节或被动止回的职责区分。
- 线上仪表：PG-101、TI-101、PG-102 为教学演示表，不显示读数；流量计 FT-101 作为内联设备保留。
- 渲染优化：同接口的法兰+螺栓、短节+弯头、单管箭头、支架与管廊均合并网格；标签做屏幕空间避让；`内部视图` 只切换外壳透明度，不做剖切封口。

## 6. 流动、阀门与状态联动

- **供源**：T-101 原料罐与 C-101 压缩机视为供源；辅料来源、各公用工程盲板端头按示意供源处理。
- **流向**：每条管线由起点接口指向终点接口；场景生成粒子、表面示踪点、方向箭头与内部脉冲纹理，方向与数据方向一致。
- **阀门 OPEN**：管线正常流动；`CLOSED`：粒子在阀门弧长位置停住，下游管线/设备失去进料并标记 `starved`，下游动画停止；`PARTIAL`：本管线降速，节流沿串联流程向下游传播。
- **恢复 OPEN**：流动与下游状态恢复；自检不因阀门操作改变。
- **阀门职责**。闸阀 GV-101 和球阀 BV-101 用于切断，蝶阀 BV-102 有定性部分开启演练，CV-101 根据正向供给被动启闭。
- **供给异常练习**。原料罐有料、预热器热媒、冷却器与冷凝器冷却水、回收泵独立气源均可切换。T-102 塔顶无已接入气源，独立观察从 PL-108 开始。找出停掉的示踪，并检查哪些通路仍可用。
- **介质视觉**：原料液（蓝）/辅料（粉）/反应液（琥珀）/塔顶气相（青，气）/冷凝液（浅青）/产品液（绿）/回收液（橙）/尾气（灰，气）/公用工程（黄）。相态影响粒子间距与速度；流体模式显示内芯与脉冲。
- **上下游追踪**：从管线图（不依赖阀门状态）BFS 追踪上游/下游/完整路径；追踪时其它设备/管线降透明，当前集合高亮。
- **工艺层聚焦**：选中 L0–L6 时聚焦该层设备与相邻管线，显示层说明卡（作用/输入/过程/输出/关键设备），地面分区加亮。
- **设备内部**：容器/塔器默认半透明；`内部视图（X-Ray）` 将全部设备外壳降至约 0.32 不透明度，观察塔内填料、除沫器、反应釜搅拌、换热管束等。剖切封口仍未实现，界面与文档均已注明。

## 8. 自检与验证

- 数据层自检（`auditPlantData`）：引用完整性、接口方向、接口存在性、管线构建、内联件挂接、层/工序一致性、孤立设备、全开阀可达性。
- 运行时自检（`window.__plant.audit()`）：在数据自检上增加已构建管线、已接入接口、内联阀数量、仪表数量。
- 页面「工艺层」页脚显示：设备连接率、管线完整率、流向完整率、设备数据完整率、内部结构完整率、全开阀可达性。本轮数据均为 **100%**，0 问题。
- 专项验证：`node scripts/verify-plant.mjs`（64 项：数据关系、接口/管线卡、阀门联动、追踪、模式、层/工序、教学、流程图、拾取、移动端、控制台错误）。第 8 轮（全流程升级）实际结果见 `docs/round-log.md` 对应章节。
- 全站回归：`npm run build`、`npm run verify`、`node scripts/verify-workshop.mjs`、`npm run smoke:prod`、发布后 `node scripts/walk-published.mjs`。

## 9. 内容边界与已知限制

- 流程为教学构型：不指向特定产品或工业装置，不设温度/压力/流量/浓度等工艺参数；阀门状态与流体动画仅表示流向与通断。
- 接口位置按现有教学模型几何换算；部分接口由场景补充（`added`），用途为教学示意，不代表厂商接管表。
- 管线走向、标高、支吊架、管廊、管径等级均为教学布置，不是管道应力、坡度、阀门布置或施工设计。
- 工艺层是流程阶段分层，不是建筑楼层；地面分区与标高尺为示意。
- 标签避让可能隐藏部分重叠标签（缩放/旋转后可恢复）；管线编号与仪表标签只在管道/流体模式或选中时显示。
- 未实现：剖切封口填充、爆炸视图/剖切平面（这两项在单台设备工作台提供，本页只做内部视图/X-Ray）、泵停机-堵塞等故障模拟（本页只把阀门状态作为操作演示）、真实仪表读数（PG/TI 为演示表盘，不显示数值）、真实管径/材质等级、工艺参数、专业评审、真机触屏试用；未使用实例化/LOD，复杂视角下绘制调用仍较高（详见 round-log 性能统计）。
- 与并行会话的「微沸喷烧流程数据模型（Phase 1/2）」相互独立：后者新增 `src/data/processTypes.ts`、`src/data/boilProcess.ts`、`src/engine/boilModels.ts`、`src/process/connections.ts`、校验/预览脚本与文档，未接入本页；本页未读取其数据。
