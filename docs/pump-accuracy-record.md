## 8. 内窥样板说明

- **入口**：吸入弯头下端的真实开放管口（世界 x≈-3.13，y≈0.20–0.54 的竖管，内径 0.12 演示）。不是虚构开口。
- **视点（8）**：吸入口（弯头下端口）→ 吸入弯头 → 吸入管 → 泵吸入口 → 叶轮进口（叶轮眼）→ 蜗壳流道 → 排出口 → 排出管出口。
- **空腔校验**：8 个视点均按通道半径/中心线公式校验位于空腔内（见 `verify-pump-template.mjs` 的 `inVoid`）；蜗壳段为预设观察点，因叶片间空间过窄，不沿叶片流道穿行（界面与入口说明已写明）。
- **交互**：拖动环顾（偏航 ±1.2 rad、俯仰 ±0.9 rad 限制）、上一站/下一站（首末站禁用）、重置视点、退出恢复外部观察；桌面与手机均可用；方向由 HUD 的屏幕箭头 + 3D 小箭头 + 教学流线共同提示。
- **限制**：内窥视角为教学视点，不是真实检修孔或内窥镜可达性结论；通道内壁无纹理；剖切封口仍未实现；视点边界依赖演示比例。
