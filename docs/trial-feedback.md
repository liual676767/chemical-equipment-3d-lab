# 真实试用方案与反馈处理（状态：待开展）

> 本文是组织真实试用的准备材料。**尚未开展任何真实学习者/教师试用**；下表所有试用记录均为空，不预填结论。

## 1. 试用对象与目标

- 学习者 3–5 名（化工相关课程学生，首次接触本站）；
- 设备教师 1–2 名（同时承担 sources-and-review.md 的专业评审）。

目标：发现阻断性问题（无法完成主流程）、理解性问题（看不懂结构/说明）、操作性问题（不顺手），并按出现频次排优先级。

## 2. 试用任务脚本（每人约 15 分钟）

| # | 任务 | 观察点 |
| --- | --- | --- |
| T1 | 从首页找到「单级离心泵」并进入学习 | 搜索/卡片是否直观；入口是否明确 |
| T2 | 用透明或剖视找到叶轮，说出它的作用 | 模式切换是否可发现；信息面板是否够用 |
| T3 | 完成 2 个观察任务（含「前往」跳转） | 任务清单是否被注意到；跳转是否有帮助 |
| T4 | 在爆炸图里指出泵轴与联轴器，再收拢复原 | 滑杆/自动展开是否顺手；复原是否可信 |
| T5 | 引导模式完成离心泵全部拆装（允许用提示） | 每步停顿时长；拖拽吸附是否容易；错误提示是否看得懂 |
| T6 | 自由模式故意装错一次（错位置/错方向），读提示后纠正 | 提示是否说明原因与下一步；能否自行纠正 |
| T7 | 刷新页面，确认进度恢复；导出学习记录 | 恢复提示是否清楚；导出是否顺利 |
| T8 | （教师）按评审清单抽查换热器与反应釜结构表述 | 科学性问题记录 |

记录方式：观察员记录每个任务的**停顿位置、误操作、口头疑问、完成时间**；试用者可在工作台顶栏「反馈」按钮直接提交（自动附带设备/模式/内容版本）。

## 3. 反馈分类与优先级

| 类别 | 示例 | 处理优先级 |
| --- | --- | --- |
| 结构/内容错误 | 零件位置、拆装顺序、文案科学性 | 最高：当轮修复并升 contentVersion |
| 交互阻断 | 无法选中/安装、提示看不懂、流程卡死 | 最高：当轮修复 |
| 性能问题 | 加载慢、拖动卡顿、移动端发热 | 高：记录加载时间与帧率，先画质降级再优化 |
| 理解/体验 | 说明不够清楚、入口难发现、吸附范围不适 | 中：按出现频次排序，≥2 人重复即优先 |
| 新需求 | 新设备、班级功能、报告导出 | 低：进入需求池，满足门槛后再排期 |

## 5. 站内反馈数据流

- 入口：工作台顶栏「反馈」按钮（带设备、模式、内容版本上下文）；
- 存储：本浏览器 localStorage，随「学习记录管理 → 导出记录」一并导出 JSON；
- 汇总：维护者收集导出文件后按上表分类；**不自动上传**，试用组织时需告知试用者这一点。
