# 工坊对象台账（第三轮更新 · 2026-11-17）

本页记录历史目录。2026-11-21 的可用类型及逐件来源见 [零件逐件台账](workshop-part-sources.md)。

本台账由 `src/workshop/catalog.ts` 程序化生成，与代码内容门禁（`npm run validate:content`）同源。

- 对象总数：**55**；可搭建（ready）：**24**；开发中（dev）：**31**。
- 状态口径：**可搭建** = 已实现三维模型、接口数据与连接规则，可在工作台放置并参与组装，且经浏览器自动化实测；**开发中** = 目录中登记了名称、结构简介、用途与学习要点，点击后展示资料卡与「开发中」标识，暂不可放置。
- 批次：第一批 = 管道 + 法兰连接附件 + 闸阀/球阀/止回阀 + 离心泵/立式储罐；第二批 = 管壳式换热器（本轮开放）及其余阀门/过滤器/仪表（开发中）；第三批 = 其余泵与旋转设备/塔器/反应釜/分离器（开发中）。
- 所有尺寸为教学示意（DN 公称直径按 GB/T 17395 / ISO 4200 系列 1 预设，法兰按 PN16 简化表），非制造图纸。
- 能力标签：整体观察 / 内部结构 / 接口连接 / 原理演示 / 部件拆装，按对象实际支持配置。

## 与实训室设备库的区分（避免重复条目）

工坊中的 `valve-ball` / `valve-gate` / `valve-check` / `pump-centrifugal` / `tank-vertical` / `heat-shell-tube` 是**管道组装用的简化连接件**：外形为低多边形示意体，重点在接口规格（DN/PN/标准/流向）与连通判定，不含实训室级别的零件级结构、剖视、爆炸与拆装练习。实训室设备库（`src/data/devices.ts`，18 台）中的法兰球阀、明杆楔式闸阀、旋启式止回阀、单级离心泵、立式固定顶储罐、管壳式换热器等是**零件级教学设备**：每台含独立零件对象、结构操作交互、原理动画，其中 13 台开放引导式拆装。两者编号、存储与用途均独立，不构成重复条目。
