# 组装工坊扩充与验收

本轮在 2026-11-20 的本地续开发副本上实施，沿用 `#/workshop`。交付时间为 2026-11-21，原 Qoder 项目目录和发布身份保留在原处。本地源码、副本构建和证据随包交接。

## 结果

逐件验收命令生成的统计为 60 种独立类型，P001–P060 全部通过。19 种原有对象复验通过，2 种旧模型修复，9 个原目录占位接入实际模型，新增 30 种。工坊页面还有 3 个既有整机教学对象和 22 个开发中项目。整机、占位、规格和实例均排除在 60 种内。

逐件台账列出实际模型、参考来源、三角面、课程和校验用配合对象。原有零件保留运行 ID，P 编号供搜索、清单对照和报告使用。模型、来源和适用课程写在 `src/workshop/expansion/`，实时缩略图使用相同模型生成器。各实例独立记录位置、旋转、规格和装配。

## 操作

1. 运行 `npm install` 与 `npm run dev`，按终端地址打开 `#/workshop`。开发副本使用 `http://127.0.0.1:5188/#/workshop`，显式复现命令为 `npm run dev -- --host 127.0.0.1 --port 5188 --strictPort`。
2. 搜索编号或名称。展开说明可查看接口、来源和课程，并为适用零件选择口径、端接或异径小端。点添加后可自由摆放，或选择「在视图中心放置」。已添加实例自动选中和聚焦。参数面板提供坐标与固定角度旋转。
3. 在「接口连接」面板选择一个实例和接口。鼠标靠近绿色接口或悬停候选行可预览吸附，按连接才写入装配关系。默认拖移移动连通子装配，按 Alt 单独拖动时会解除相关连接。
4. 「组装任务」里有三门基础课。法兰连接装配使用 17 个实例与 16 处连接，管路单元组装使用 9 个实例与 8 处连接，离心泵结构装配使用 12 个实例与 12 处配合。每门都可从空场景操作，参考方案为独立对照层。泵装配支持展开和复位。

## 规格与模型依据

- 教学管件、法兰和螺纹沿用工坊预设。连接规则检查端型、管径、螺纹体系与已声明的内外型、流向、法兰孔模式，以及选定配合的轴向和角向。螺栓、螺母、垫圈和支撑件保留独立关系，管路拓扑只沿流体接口传播。
- 泵课复用站内单级悬臂泵教学模型，轴承、密封与轴系使用统一装配基准。未核验厂商型号、制造公差及现场尺寸，省略第二处轴支承、电机、护罩及部分辅助密封件。KSB、Goulds 与 John Crane 资料核对构型和工作面。
- 仪表区分过程端、套管和测温元件的机械安装，附信号说明。转子流量计连接检查要求竖直且自下向上。压力、流量、液位等没有数值模型读数。安全阀用于安装练习，无整定或泄放计算。
- 公开查阅的厂商和标准页面只提供结构或使用依据。没有再分发第三方 CAD 文件，也没有向转换服务上传项目模型。原站的外观 GLB 仍由其原模块管理。

## 存档与验收

继续读取 `chem3d-workshop:v1` 和既有 schema 1。新存档保留欧拉角，并输出四元数、单位缩放、类型编号与规格编号。保存实例、连接、机械配合、分组和课程进度。缺失资产、悬空引用、异常数值或损坏 JSON 会给出提示。导入旧版方案可继续编辑。

```powershell
$env:VERIFY_GPU = '1'
$env:VERIFY_BASE = 'http://127.0.0.1:5188/'
node scripts/verify-workshop-expansion.mjs
node scripts/verify-workshop.mjs
node scripts/verify-piping-assets.mjs
node scripts/pump-workshop-mechanics.mjs
npm run verify
npm run verify:factory
npm run build
```

生产版可运行 `npm run preview -- --host 127.0.0.1 --port 4188`，然后运行 `node scripts/smoke-workshop-expansion.mjs`。该测试从旧版方案进入生产页面，在保留原焊接边的同时装配套管和热电偶，再刷新检查原连接和新机械配合。

逐件报告含 60 行模型与装配证据、5 种 CSS 视口、三个任务的浏览器完成结果和 50、100 实例的性能采样。逐件执行实际添加、选中、移动、旋转、删除、撤销和刷新恢复，配合用对应夹具校验并做导入导出往返。三门课在浏览器从零连接，并刷新核对连接和完成进度。手机尺寸为模拟视口。报告中的帧率由桌面无头 Edge 的连续 rAF 帧计算，场景初始化时间从创建实例到首帧采样，不含冷启动和网络加载。报告保留渲染器、绘制调用和三角面数。

验收数据位于 `outputs/workshop-expansion/report.json`，依据说明位于 [零件逐件台账](workshop-part-sources.md)。本地构建输出位于 `dist/`。
